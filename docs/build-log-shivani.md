## 1. What I built

A fully functional React frontend for the Smart Articulation system that works end-to-end with zero backend dependency. The app has three pages (Home, Practice, Progress) connected by react-router-dom, a recording hook that captures real microphone input, a mock scoring client that simulates the exact contracted API shape with realistic latency and score distribution, and a five-state feedback panel that handles every edge case the contract allows. ## 4. The mock strategy, explained

`USE_MOCK` is the single boolean in `src/api/client.js` (line 4). When `true`:
- `scoreAttempt` sleeps 900 ms then calls `mockScore(meta)`.
- `mockScore` generates per-phoneme scores in the range 35–100, derives `status` from thresholds (≥75 correct, ≥50 close, else incorrect), produces timing data with realistic increments, and assembles the full contracted response shape including `overall_score`, `verdict`, `expected`, `heard`, `phonemes[]`, `tip`, `duration_ms`, `engine: "mock"`.

**Flipping `USE_MOCK` to `false` requires changing N = 0 other lines.** The `scoreAttempt` signature and the response object shape are identical. No component reads `USE_MOCK`. No shim, no transform.

## 6. Decisions I made

| Decision | Rationale |
|---|---|
| `App.jsx` is only a router shell | Layout is per-page so each page controls its own `<h1>` for SEO/accessibility |
| `NavLink end={to === '/'}` | Without `end`, `/` matches all paths and stays active always |
| `PhonemeCard` shows both `displayText` and `symbol` badge | At word/sentence level the text is "sun" but the target phoneme is "S" — both must be visible |
| `Articulation` receives `viseme` + `playing` props | Tanisha documented the Oculus viseme set in phonemes.json; these are the props her component will need |
| No `useReducer` | Spec forbids state management libraries and says `useState` is sufficient — four booleans are clear |
| `session.js` is module-scope array | Spec says in-memory only, no storage. Module scope survives navigation without persisting across tabs |
| `items.length === 0` check before rendering practice body | `items[0]` would crash if we skip this; spec requires graceful empty state |

## 10. Integration notes
